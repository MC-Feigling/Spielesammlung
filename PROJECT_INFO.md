# Spielesammlung

Kinderfreundliche Browser-Spielesammlung (2–4 Spieler, ein Laptop).

## Stack

- Nuxt 4, Vue 3 Composition API, TypeScript, TailwindCSS
- Bun (kein npm)
- Ziel: elementaryOS, lokal im Browser

## Befehle

```bash
./start.sh          # One-Click: Bun + deps + Dev-Server (+ Browser)
bun install
bun run dev
bun run test
bun run build
bun run preview
```
